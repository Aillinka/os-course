# Практическая работа №9. Распределение памяти

## Цель работы

Изучить алгоритмы распределения оперативной памяти, реализовать стратегии First Fit, Best Fit, Worst Fit и Buddy System, а также исследовать внешнюю и внутреннюю фрагментацию памяти.

## Используемые инструменты

- Ubuntu Linux
- Python 3
- Язык программирования C
- GCC
- mmap
- Valgrind
- Matplotlib

## Вариант A. Алгоритмы распределения памяти

Были рассмотрены и реализованы три стратегии распределения памяти:

- **First Fit** — выбирает первый свободный блок подходящего размера.
- **Best Fit** — выбирает наименьший свободный блок, в который помещается запрос.
- **Worst Fit** — выбирает самый большой свободный блок.

Также была реализована визуализация состояния памяти после операций выделения и освобождения.

### Внешняя фрагментация

Внешняя фрагментация возникает, когда свободная память разделена на небольшие несмежные блоки. В результате запрос может завершиться неудачей, даже если суммарного объёма свободной памяти достаточно.

## Вариант C. Собственный распределитель памяти

Для реализации собственного распределителя памяти использовался язык C и системный вызов mmap, позволяющий выделить отдельную область виртуальной памяти.

Реализованы следующие функции:

- `my_malloc()` — выделение памяти;
- `my_free()` — освобождение памяти;
- `my_realloc()` — изменение размера выделенного блока;
- `merge_free()` — объединение соседних свободных блоков.

Для выбора свободного блока реализованы две стратегии:

- First Fit — выбор первого подходящего блока;
- Best Fit — выбор наименьшего подходящего блока.

### Сценарии тестирования

1. Множество небольших выделений памяти.
2. Чередование выделения и освобождения памяти.
3. Выделение крупных блоков памяти.

Результаты сравниваются с системным распределителем памяти glibc по времени выполнения. Дополнительно измеряется пиковое потребление памяти RSS.

### Проверка Valgrind

Программа проверяется с помощью Valgrind Memcheck для обнаружения ошибок управления памятью и утечек.

*Численные результаты и окончательный вывод будут добавлены после выполнения тестов.*
